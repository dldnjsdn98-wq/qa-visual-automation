## 구현 결과

`ocr_execute(source_bytes, source_facts, profile_manifest)`를 실제 PaddleOCR 3.7 adapter로 구현했다. 실행 전에 profile platform, locale table, 전체 설치 distribution 버전, single OpenCV distribution, Linux native package 버전/architecture/copyright hash, model file 6개의 size/SHA-256을 검증한다. `QA_OCR_MODEL_ROOT`가 없거나 모델이 없거나 변조되면 download/fallback 없이 fail-closed한다.

입력은 Pillow raw raster 기준 RGB8로 decode하며 EXIF transpose를 적용하지 않는다. RGB row-major pixel hash, original-raster polygon canonicalization, clipping, stable region order, raw audit, closed output schema, RFC8785 runtime digest를 생성한다. CPU/FP32/`paddle_static`/one-thread를 고정하고 document orientation, unwarping, text-line orientation, MKLDNN, CINN을 끈다.

Verification은 Unicode 15 NFC + 명시적 White_Space `norm-v1`, exact/normalized/integer Levenshtein rational score, deterministic one-to-one global assignment, 95/85 경계, missing/empty/no-text 분리와 계약 bounds를 구현했다. Locale lookup은 `_`를 `-`로 바꾼 뒤 case-insensitive하게 수행하며 허용 table은 `en,en-US,en-GB`, `ja,ja-JP`, `zh-Hans,zh-CN`, `zh-Hant,zh-TW`, `ko,ko-KR`만 포함한다.

Registry는 현재 OS와 manifest `platform_system`이 일치하는 qualified profile만 `AVAILABLE`로 표시한다. 같은 profile identity를 다른 platform이나 model로 재지정하지 않는다.

## 실패 이력 보존

Preparation report에 기록된 broken project `.venv`, 초기 Docker permission denial과 pre-activation NOT_RUN 이력은 그대로 유지한다. Runtime qualification 중 발생한 실패도 성공 결과로 덮어쓰지 않았다.

1. Windows 첫 native import는 user cache write permission 때문에 실패했고 역할 전용 cache 환경변수로 통과했다.
2. Linux 첫 import는 `libGL.so.1` 부재로 실패했다.
3. Linux 두 번째 import는 `libgomp.so.1` 부재로 실패했다.
4. BOS recognizer 단일 연결이 매우 느려 중단했고 HTTP Range 8개 병렬 획득 후 exact size로 재조립했다.
5. Windows locale collector가 CP949로 Japanese 출력을 잘못 decode했고 child/runner UTF-8 고정 후 통과했다.
6. Profile generator는 OCR-only venv의 `rfc8785` 부재로 실패했고 양 OS Worker lock에 `rfc8785==0.1.4`를 추가했다.
7. 대형 adapter patch의 delete/add 동시 형식이 거부되어 단일 update patch로 적용했다.
8. 첫 profile generator 실행은 `PYTHONPATH` 부재로 `worker` import에 실패했고 project root를 명시해 통과했다.
9. sandbox 내 Docker socket 접근은 permission denied였고 승인된 Docker 실행으로만 계속했다.
10. read-only compileall은 `__pycache__` write denial로 실패했고 bytecode를 쓰지 않는 AST parse로 문법을 검증했다.
11. 첫 Linux native-profile readiness smoke는 tab delimiter parsing 결함 때문에 `ENGINE_UNAVAILABLE`로 닫혔고 원인을 확인해 수정한 뒤 clean install/actual OCR을 다시 통과했다.
